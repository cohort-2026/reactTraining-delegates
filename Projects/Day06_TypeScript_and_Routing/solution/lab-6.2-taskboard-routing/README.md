# TaskBoard: Lab 6.2 routing checkpoint

This checkpoint adds React Router to the typed TaskBoard. It has a Dashboard, project pages, Settings and a Not Found page. Each task belongs to a project, and the Dashboard search query is synchronized with the URL.

## Run

```bash
npm install
npm run dev
```

Use `npm run lint` to run ESLint and `npm run build` to type-check and build. The first run loads starter tasks from JSONPlaceholder, so it needs an internet connection.

Lab 6.3 builds on this checkpoint by protecting Settings with a mock login.
