# TaskBoard: Day 3 starter

Your TaskBoard project as it stands at the end of Day 2. It is an exact copy of `Projects/Day02_Modern_JavaScript_and_Your_First_React_App/solution/lab-2.3-taskboard`, with `TODO` comments in `src/App.jsx` and `src/App.css` where today's labs change the code.

All three Day 3 labs are built inside this project:

| Lab | What you add |
|---|---|
| 3.1 Build a Reusable Component Set | `src/components/ui/Button.jsx` and `src/components/ui/Card.jsx` |
| 3.2 Render a Product Catalogue from Static Data | `src/components/catalogue/` (`products.js`, `ProductCard.jsx`, `ProductGrid.jsx`) |
| 3.3 TaskBoard: Static Task List UI | `src/data/tasks.js`, `src/components/Header.jsx`, `Board.jsx`, `Column.jsx`, `TaskCard.jsx` |

If you already have your own TaskBoard from Day 2, keep using it. Use this folder only if you need a clean starting point.

## How to run

```bash
npm install
npm run dev
```

Open the **Local** URL Vite prints (usually `http://localhost:5173`). Run `npm run lint` to check your code with ESLint.
