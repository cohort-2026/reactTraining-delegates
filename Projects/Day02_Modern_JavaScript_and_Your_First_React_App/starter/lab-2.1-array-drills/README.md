# Lab 2.1 starter: Data Transformation Drills

**Goal:** fluency with `map`, `filter`, `find`, `reduce`, spread and destructuring. **Suggested time:** 40 min. **No `for` loops allowed.**

## What is here

`lab2-1.js` with the array of 6 products already written (step 1), and TODO comments numbered to match the steps in your Day 2 handbook (**Lab 2.1**).

## How to use it

1. Copy `lab2-1.js` into your `react-course/day2` folder.
2. Run it straight away to check Node is working. It prints nothing yet, because every step is still a TODO:

   ```bash
   node lab2-1.js
   ```

3. Work through the TODOs one at a time, running `node lab2-1.js` after each one.
4. When everything is logged with labels, commit:

   ```bash
   git add .
   git commit -m "Add array drills"
   ```

No `package.json` is needed: this file does not use `import` or `export`.
