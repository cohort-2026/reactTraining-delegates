# Lab 1.2 starter: Build a Static Profile Page

**Goal:** a personal profile page using semantic HTML and CSS layout. **Suggested time:** 50 min.

## What is here

- `index.html`: the page skeleton (doctype, `head`, `body`) with TODO comments where each part of the page goes.
- `style.css`: a box-sizing reset and base font, with TODO comments for each layout rule.

The TODO comments are numbered to match the steps in your Day 1 handbook (**Lab 1.2**).

## How to use it

1. Copy `index.html` and `style.css` into `react-course/profile-page/`. (This covers steps 1 and 2 of the handbook: the skeleton is already generated. You still need to add the `link` tag.)
2. Work through the TODOs in `index.html`, then in `style.css`. Replace each TODO comment with your code.
3. Open the page by double-clicking `index.html` in File Explorer or Finder. After every change, save and refresh the browser.
4. Right-click the page and choose **Inspect** to check your layout in DevTools (step 7).
5. Commit and push (step 8):

   ```bash
   git add .
   git commit -m "Add profile page layout"
   git push
   ```
