# Lab 1.3 starter: Tip Calculator and Grade Checker

**Goal:** practise variables, conditionals, functions, arrays and objects in Node.js. **Suggested time:** 50 min.

## What is here

`lab1-3.js` with empty function stubs for `calculateTip`, `totalWithTip` and `getGrade`, an empty `students` array, and TODO comments numbered to match the steps in your Day 1 handbook (**Lab 1.3**).

## How to use it

1. Copy `lab1-3.js` into `react-course/js-basics/` (this is step 1).
2. Open the VS Code terminal in `js-basics` and run the file straight away:

   ```bash
   node lab1-3.js
   ```

   You will see:

   ```text
   Tip: Rundefined
   Total with tip: Rundefined
   ```

   That is expected: the functions have no `return` yet, so they give back `undefined`.
3. Work through the TODOs one step at a time, running `node lab1-3.js` after every step.
4. When the output lists every student with a grade and the pass count, commit and push (step 8):

   ```bash
   git add .
   git commit -m "Add tip calculator and grade checker"
   git push
   ```

## Done when

- [x] All functions return values (no `undefined`)
- [x] The output lists every student with a grade
- [x] The pass count is correct
