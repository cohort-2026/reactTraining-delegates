# Lab 1.2 solution: Static Profile Page

A complete semantic profile page using Flexbox for the navigation and a responsive CSS Grid for the three skill cards.

## Open the page

Open `index.html` directly in a browser. The stylesheet is local; the portrait image is loaded from Unsplash and requires an internet connection.

The profile text and `hello@example.com` contact address are sample content. Replace them with your own details when adapting the page.
