# Day 1 projects: Web and JavaScript Essentials

This folder holds a starting point and a finished example for each of today's three labs. The lab steps themselves are in your Day 1 handbook (`Markdown Handbooks/Day01_Delegate_Handbook_Web_and_JavaScript_Essentials.md`), section **Hands-on labs**.

**Start from `starter/`.** Copy the lab's starter folder into your own `react-course` folder, then follow the handbook steps. Only open `solution/` once you have tried on your own, or if you fall behind and need to catch up.

| Lab | Starter | Solution | How to run |
|---|---|---|---|
| 1.1 Environment Setup and First GitHub Repository | `starter/lab-1.1-react-course/` (step-by-step commands and a README template) | `solution/lab-1.1-react-course/` (an example README and a "finished setup" checklist) | Nothing to run: you type the commands in your terminal |
| 1.2 Build a Static Profile Page | `starter/lab-1.2-profile-page/` (`index.html` skeleton and `style.css` with TODOs) | `solution/lab-1.2-profile-page/` | Double-click `index.html` to open it in Chrome or Edge |
| 1.3 JavaScript Exercises: Tip Calculator and Grade Checker | `starter/lab-1.3-js-basics/` (`lab1-3.js` with function stubs) | `solution/lab-1.3-js-basics/` | `node lab1-3.js` |

## Where the files go in your own work

The handbook builds everything inside one `react-course` folder, which is also your first GitHub repository:

```text
react-course/
  README.md          Lab 1.1
  profile-page/      Lab 1.2 (index.html, style.css)
  js-basics/         Lab 1.3 (lab1-3.js)
```

So when you copy a starter, copy its **contents** into the matching folder: `lab-1.2-profile-page/*` into `react-course/profile-page/`, and `lab-1.3-js-basics/lab1-3.js` into `react-course/js-basics/`.

## Requirements

- Node.js LTS (Node 24) for Lab 1.3. Check with `node -v`.
- Chrome or Edge for Lab 1.2.
- Git and a GitHub account for Lab 1.1 and for committing the other two labs.
