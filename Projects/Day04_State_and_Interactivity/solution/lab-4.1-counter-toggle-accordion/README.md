# TaskBoard: Lab 4.1 solution (Counter, Toggle and Accordion)

Built on: `Projects/Day04_State_and_Interactivity/starter/taskboard`.

This checkpoint adds the Day 4 state exercises below the existing static TaskBoard.

## How to run

```bash
npm install
npm run dev
```

Run `npm run lint` and `npm run build` to check the project.

## What changed

- `Counter` supports plus, minus (minimum zero), Plus 5 with updater functions, and reset.
- `ThemeToggle` switches a local wrapper between light and dark classes.
- `Accordion` has three independently toggled items and parent-controlled Show all/Hide all.
